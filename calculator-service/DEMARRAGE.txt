📋 ÉTAPES DE DÉMARRAGE RAPIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  DÉMARRER L'APPLICATION

   💾 Windows (Simple) : Double-cliquer sur 👉 start.bat

   ⌨️  Ligne de commande :
      .\mvnw spring-boot:run

   💻 Via le JAR :
      java -jar target\calculator-service-1.0.0.jar


2️⃣  VÉRIFIER QUE ÇA MARCHE

   🌐 Ouvrir dans le navigateur :
      http://localhost:8080/swagger-ui.html

   ✅ Vous devriez voir l'interface Swagger avec les 4 endpoints


3️⃣  TESTER UNE OPÉRATION

   Cliquer sur "Multiply" dans Swagger
   Entrer les paramètres : a=10, b=5
   Cliquer sur "Try it out"
   ➜ Le résultat devrait être 50


4️⃣  EXÉCUTER LES TESTS

   💾 Windows (Simple) : Double-cliquer sur 👉 run-tests.bat

   ⌨️  Ligne de commande :
      .\mvnw clean test

   ✅ Résultat attendu : 34/34 tests réussis


5️⃣  CONSULTER LA DOCUMENTATION

   📖 README.md              → Documentation complète (français)
   ⚡ QUICKSTART.md          → Guide démarrage rapide
   📚 API_EXAMPLES.md        → Exemples de requêtes (cURL, Python, etc.)

   ➜ Essayer : http://localhost:8080/swagger-ui.html
